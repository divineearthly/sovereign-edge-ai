# Vedic-Native-SLM-1.1B

1.1B parameter Small Language Model for ARM64 edge devices.

## Vedic Kernel Integration
- Nikhilam Sparsha: 3.15x softmax speedup
- Anurupya KV Cache: 341x memory reduction
- Vilokanam: Script-aware vocabulary filtering

## Intended Use
Offline agricultural AI for Indian farmers, multilingual Q&A

## Languages
English, Hindi, Bengali, Assamese, Tamil

## Limitations
ARM64 only. No GPU support. 4GB RAM minimum.
